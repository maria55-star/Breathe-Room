# Breathe Room

O aplicație Android care te ajută când simți că stresul crește:
îți notezi cum te simți, faci un exercițiu de respirație ghidată
și poți anunța rapid o persoană de încredere.
Nu este o aplicație medicală și nu pune diagnostice.

## Ce poate face aplicația

**Partea 1: Cum te simți și respirația** ([Persoana A])
- [x] Check-in: alegi nivelul de stres, de la 1 la 5
- [ ] Exercițiu de respirație cu animație și vibrație
- [ ] Verificare înainte și după exercițiu

**Partea 2: Jurnal și istoric** ([Persoana B])
- [ ] Jurnal cu notițe și nivelul de stres pe zile
- [ ] Grafic cu evoluția
- [ ] Ce te-a ajutat cel mai mult

**Partea 3: Sprijin** (împreună)
- [ ] Persoane de încredere: le salvezi și le suni sau le scrii dintr-un tap
- [ ] Setări și confidențialitate (datele rămân pe telefon)

## Cum e făcută
Kotlin și Jetpack Compose pentru ecrane, Room pentru datele salvate
pe telefon, ViewModel pentru starea aplicației.
